# CreditIQ mobile app visual source of truth — V2 Luxe

Use the approved 2026-09-09 reference boards as the visual direction for `/app-preview`.

## Visual system
- Midnight/navy base surfaces with warm cream contrast panels.
- Restrained champagne-gold accent for primary actions, selected states, scores, progress and CIRA.
- Editorial serif display headlines paired with clean sans-serif UI copy.
- Real card artwork from `/public/card-art` wherever a card is shown.
- Travel/lifestyle imagery is used as atmosphere, never as a text background without a dark readability overlay.
- Rounded premium mobile surfaces, subtle 1px borders, glass/blur only when legibility remains high.
- CIRA remains the raised visual centre of the six-item bottom navigation.

## Navigation
Home · Wallet · CIRA · Travel · Cards · Menu
Spend Smart is a first-class flow launched from Home / merchant checks, not another persistent tab.

## Demo data truth
Any prototype-only fare, hotel price, points balance or reward value must be labelled as demo/projected. Live production pricing must continue to obey the Travel decision contract and source-authority rules.

## India demo priority
Investor demo routes must prominently include Indian domestic examples such as BLR→DEL/BOM/GOI/HYD/MAA and domestic stays such as Goa, Mumbai, Delhi and Bengaluru. These prototype examples do not replace live-provider verification.
