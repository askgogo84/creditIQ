# UI/UX Brief — CreditIQ Light/Copper
Mobile first ≥375px. Existing design: white background, restrained copper, verified green #4FBF87 only for verified sources, estimated neutral grey. Preserve existing Travel UI and do not introduce another design system.
Fare card must show: "Total for X adults", date, cabin, currency, provider, fetched time, provider completeness, booking link status, and "price can change at checkout". Cached discovery has distinct label and cannot trigger watcher.
Group search controls must not silently drop adults/children/return legs. When unsupported, show a precise explanation and a link to supported one-way adult options.
Watcher controls (future UI): threshold amount, comparator, check frequency/cost, expiration, enable/disable, alert history, confirmation that app only watches and never purchases.
Shopping quotes must show seller, item total, shipping, tax, freshness, source, and a separate estimated card-rewards field.
